# 0.5.21 验证

验证日期：2026-10-08。宿主：DSH 0.2.1-alpha.1，macOS，Node.js 22+。

## 真实宿主

使用独立 DSH_HOME 和 Web profile 加载仓库包。实际验证组合包注册、原生压缩服务挂载、已认证连接上的插件请求、设置读取保存、旧版本保存拒绝、模型目录保留和历史导入。0.5.20 的隔离验证没有使用生产接入配置。0.5.21 按用户授权替换了生产 DSH Web 的旧外部后台入口，所有现有 profile 的模型配置和摘要设置保持一致，原生压缩继续挂载。

## 可重复测试

`npm run validate` 检查源码语法，并运行 `test/standalone*.test.js`。宿主服务与压缩生命周期测试加载真实 DSH SessionStore、消息投影、Basic 和 Cordis；模型流由本地确定输出提供，避免收费及模型随机性。

覆盖后台归档完整性、真实工具消息边界、20K 预算关段、跨进程设置竞争、跨宿主任务租约、取消后迟到结果拒绝、摘要单独运行不改活动上下文、原生与接管切换、准备时不替换、摘要树还原，以及原生界面注册与交互。

旧 `test/` 中没有 standalone 前缀的文件保留为 0.3 历史测试，现行验证入口明确使用新版本测试。旧浏览器展示页只作历史资料，不作为现行运行入口，也不包含在安装包中。

## 范围

真实宿主检查验证服务接线。界面交互采用实际客户端代码和本地连接响应测试，并已在真实 Chrome 验证 0.5.21 插件详情中的摘要设置、模型、20K 分块和运行中组件。截图保存在本地验收目录，不公开用户浏览器信息。摘要质量和模型供应商可用性需由实际使用继续判断。Windows/Linux CI 配置已包含，但本机不会代替远端执行结果。

## 0.5.21 部署验收

40 项测试全部通过。修复了原生 ready 节点的可见性、包装节点的语义展开和会话摘要计数；冷会话按持久化游标增量读取，历史导入保持真实活动时间。迁移核对完整节点内容与来源、子引用，相同节点保留，冲突拒绝覆盖。

从旧共享归档迁入 562 个 DSH 会话、133,988 条原始事件、323 个原生摘要节点和 47 个后台归档摘要节点。源库与配置备份保留。导入没有调用模型。

本地及既有公网 DSH 入口的认证请求均读取到 0.5.21、已保留的摘要配置和可读的 V9 主线程／顾问原文与摘要。插件请求使用同一个 DSH 连接，不依赖另外的本机后台地址。未在实际 Windows 浏览器中操作，公网接口通过不等同于 Windows 界面已验收；远程加载速度仍受隧道网络影响。

首次打开只读设置，对话列表在切换到对话页时加载。本轮验收没有发送任务消息或制造收费模型请求。
